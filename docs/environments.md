# Environments

## Local

- developer-owned runtime
- local API endpoint by default
- `.env.example` is the only committed env artifact

## Dev

- shared feature integration
- flexible feature flag validation
- lower-risk diagnostics enabled

## Stage

- release candidate validation
- production-like API and asset configuration
- focused regression and acceptance testing

## Prod

- immutable build artifacts
- strict environment injection
- monitored user journeys and alerting
